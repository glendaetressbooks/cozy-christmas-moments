# Cozy Christmas Moments landing page

GitHub Pages package for Glenda E. Tress Books.

## Publish

1. Create a public GitHub repository named `cozy-christmas-moments`.
2. Upload every file from this package to the root of the repository.
3. Commit the files to the `main` branch.
4. In **Settings → Pages**, choose **Deploy from a branch**, then select **main** and **/(root)**.
5. The page will appear at:
   `https://glendaetressbooks.github.io/cozy-christmas-moments/`

The page includes the updated cover, Amazon links, six preview images, the
shared MailerLite sampler form, and a link back to the main books homepage.
